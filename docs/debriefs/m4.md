# Builder's Debrief — M4: Closing the Synthetic→Real Gap (in progress)

> Plan: `docs/M4_PLAN.md`. Baseline = M3 from-scratch CNN (1.22M params, synthetic v1,
> 8k clips): OpenMIC trained-9 AP 0.785, synthetic test map_leaf 0.923. Δs are paired
> artist bootstraps (400 resamples) on OpenMIC test trained-9 mean AP.

## Results (2026-10-09)

| lever | OpenMIC trained-9 | Δ vs baseline [95% CI] | OpenMIC untrained-11 | synthetic map_leaf |
|---|---|---|---|---|
| baseline | 0.785 | – | 0.326 | 0.923 |
| **L1 co-train, all OpenMIC train (14,915 real clips)** | **0.870** | **+0.085 [+0.070, +0.099]** | 0.725 | **0.876 ↓** |
| L1 co-train, commercial-licence clips only (≈1.3k) | 0.804 | +0.019 [+0.007, +0.032] | 0.583 | 0.856 ↓ |
| L2 production randomization v2 (re-rendered 10k) | 0.783 | −0.002 [−0.012, +0.010] | 0.331 | – |

**1. Real co-training buys coarse real-world accuracy and costs fine-grained accuracy.**
- **Gains:** organ +0.13, synth +0.17, trumpet +0.15, bass +0.09. The model now clearly
  beats MERT-MLP on real music (+0.083, CI [+0.064, +0.100]).
- **Costs:** on synthetic test, the *fine* distinctions regress. Rhodes 0.77→0.61, FM
  0.84→0.70, nylon 0.89→0.80, synth lead/pluck ~−0.08 each; map_leaf 0.923→0.876.
- **Cause:** 15k coarse real clips outweigh 8k fine synthetic ones, so the shared features
  tilt toward coarse family identity.
- **Untrained classes jumped** (0.33→0.73), which is the honest tell that part of the gain
  is *learning OpenMIC itself*. Train and test come from the same source and the same
  crowd-labelling, so OpenMIC test is no longer an independent judge for L1 models.
  **An independent real test (golden set / MoisesDB) is required before claiming L1 helps
  real-world recognition in general.**

**2. The licence cost, measured.** Restricting real co-training to commercially usable
clips (~9% of OpenMIC) keeps only a quarter of the coarse gain (+0.019 vs +0.085).

**3. Production randomization (L2) did nothing measurable.** It added convolution rooms,
amp/cab EQ, saturation, MP3 round trips and noise. So the real-music gap isn't explained
by these production differences; more likely by **source timbre diversity** (L3, now
rendered) and **musical context** (Lakh MIDI arrangements vs real playing). A plausible
negative result, recorded as such.

## Rigor suite (Bradley: "make sure the synthetic tests are actually unbiased")

**R-a. Leave-source-out (the key test).** v4 render: 10k clips, all 38 mapped sources,
the octave-fit fix, 18 (source, leaf) pairs held out of train/val. Each test window is
rendered twice: once with training sources (`test`) and once with the held-out sources
(`test_lso`, same songs and arrangements, different instruments).

| test | map_leaf | hier_f1 |
|---|---|---|
| seen sources (standard synthetic test) | 0.930 | 0.911 |
| **unseen sources** | **0.607** | 0.701 |

**The standard synthetic test is badly optimistic: the model largely memorizes specific
sampled instruments.** Per leaf (seen → unseen):
- **Generalizes:** distorted guitar 0.99→0.96, trumpet 0.99→0.94, cymbals 1.00→0.97, 808
  kit 1.00→0.89, acoustic kit 0.99→0.86, clean guitar 0.93→0.79, Rhodes 0.76→0.64.
- **Collapses:** picked bass 0.93→0.16, synth bass 0.92→0.19, fingered bass 0.95→0.23,
  nylon 0.97→0.29, synth lead 0.92→0.31, upright 0.96→0.46, steel 0.99→0.50.
- **Pattern:**
  - Leaves trained on ≥3 *distinct* instruments generalize.
  - Leaves with 1–2 instruments collapse. Fingered and picked bass were the same sampled
    bass played two ways (plus a GM bank), so the model learned that bass's quirks, not
    the playing technique.
- **OpenMIC can't see any of this** (coarse classes). From now on **LSO map_leaf is the
  primary synthetic metric**; the seen-source number is reported only as a
  memorization gap.

**R-b. Leave-production-out.**
- v1-production model on v2-production renders: 0.923 → 0.877.
- A model *trained* on v2 production: 0.879 on the same test.

So v2 production is just harder (MP3 / noise / bandwidth). The model isn't keyed on the
production style.

**R-c. Non-timbre shortcut baseline.** A model on tempo, onset density, loudness, dynamic
range, chroma and coarse register only (no spectral shape): map_leaf 0.390, vs prior
0.219 and model 0.923.
- **Explains ~50% of the model's gain** for 808 sub (register), distorted guitar
  (compressed dynamics, itself partly timbral) and cymbals (hat rhythm).
- **Explains ≤20%** for fingered/picked bass, FM e-piano, pads, organ and upright. Pluck 4%.

The fine distinctions aren't arrangement or register shortcuts. They're timbre, but the
timbre of *specific sources* (R-a).

**R-d. Register giveaway fixed.** Octave fitting no longer shifts a phrase when ≥80% of its
notes already fit the source's range (applied to v4).

**L3 (9 more sources) on real OpenMIC: no change** (−0.001, CI [−0.013, +0.012]). Coarse
real music doesn't reward source diversity, but LSO shows it's what fine-grained
generalization needs.

**R-e. Does pretraining generalize across sources better? No.** Same v4 split, frozen
probes:

| model | seen sources | **unseen sources** |
|---|---|---|
| from-scratch CNN | 0.930 | **0.607** |
| MERT-95M probe | 0.819 | 0.517 |
| CLAP probe | 0.481 | 0.335 |

- **Scratch − MERT on unseen sources: CI [+0.074, +0.103].**
- **MERT wins only on bass technique:** picked 0.60 vs 0.16, fingered 0.36 vs 0.23.
- **MERT loses elsewhere:** clean guitar 0.41 vs 0.79, Rhodes 0.42 vs 0.64, FM 0.29 vs
  0.43, organ 0.38 vs 0.53.

Every model degrades the same way on unseen instruments, so the bottleneck is the
*training data's instrument diversity*, not the backbone. That's the clearest statement
yet of M4's thesis.

**R-f. Training-seed variance (needed to read any single-run delta).** v4 retrained with 3
seeds, scored on the same unseen-source test: 0.607 / 0.596 / 0.601, i.e. **mean 0.601 ±
0.006**. Bootstrap CIs cover test-set sampling only; seed spread is the other noise source.

**L3b. Wider synth recipes + Swagbass (v5): worse.** The v5 model on the *same* v4
unseen-source test scored 0.578 (Δ vs v4 seed-0 CI [−0.038, −0.019]), about 4 seed-SDs below
the v4 mean.
- **Losses:** synth pluck 0.65→0.48, 808 sub 0.88→0.80, clean guitar 0.79→0.71.
- **Gain:** pad 0.64→0.71.
- **Reading:** randomizing oscillator/filter engines across lead/pluck/analog-bass recipes
  blurred the envelope-defined boundaries between those leaves. "More variety" helps only
  when it varies *nuisance* factors (which instrument), not the factors that *define* the
  class (attack/decay shape). Patch profile v2 stays opt-in; the default remains v1.
- **Not yet separated:** the Swagbass coarse-label effect (bass.electric only). A clean
  ablation would add it alone.

## First independent real fine-grained test: MoisesDB (2026-10-10)

- **Data:** 240 real songs (43 artists), one 10 s window per song (from 20 s), labels from
  per-track stems. Test-only; MoisesDB is NC-SA and is never trained on.
- **What can be scored:** only 9 leaves have positives. Of those, `voice.sung` is excluded
  because no synthetic clip is ever labelled voice. Synthetic-only models score *below
  chance* on it (0.72–0.84 vs 0.87 prevalence), which would mask everything else.
- **Bootstrap:** 1,000 resamples, paired, grouped by artist.

| model | trained-leaf mAP (8 leaves) |
|---|---|
| prevalence (chance) | ~0.24 |
| CLAP probe | 0.329 |
| MERT-95M probe | 0.410 |
| scratch v1 (8k synth) | 0.410 |
| **scratch v4 (38 sources, octave fix)** | **0.431** |
| scratch v5 (wider synth recipes) | 0.412 |
| scratch co-trained, all OpenMIC | 0.368 |
| scratch co-trained, commercial OpenMIC | 0.417 |

Paired Δ [95% CI]:
- **scratch v1 − MERT: +0.000 [−0.044, +0.047].** Tie, again. The from-scratch 1.2M-param
  CNN matches the 95M pretrained model on real music.
- MERT − CLAP: +0.081 [+0.027, +0.160]. Scratch v1 − CLAP: +0.081 [+0.023, +0.166].
- v4 − v1: +0.021 [−0.013, +0.061]. v5 − v4: −0.019 [−0.058, +0.013]. Direction agrees
  with LSO (v4 > v1, v5 worse), but not significant on 240 clips.
- **Co-training on all of OpenMIC − v1: −0.042 [−0.102, −0.004].** The +0.085 OpenMIC gain
  **does not transfer** to an independent real set; fine leaves get *worse*. That confirms
  the earlier suspicion that L1 mostly learned OpenMIC itself. One exception: coarse
  `voice` AP 0.79→0.99, since synthetic data has no voice at all.
- Commercial-only co-training − v1: +0.007 [−0.030, +0.040]. Neutral.

Per leaf (AP; chance in brackets):
- **Learned well:** distorted guitar 0.71–0.78 (0.28), acoustic kit 0.95–0.98 (0.79).
- **Above chance:**
  - synth lead 0.23–0.40 (0.07);
  - upright bass 0.19–0.34 (0.04), n=9;
  - clean guitar 0.31–0.39 (0.24);
  - piano 0.42–0.56 (0.36). MERT is best on piano.
- **Near chance:** synth pad 0.19–0.28 (0.15); bowed section (n=5, uninformative).

**Coverage limit (important):** MoisesDB's track types can't distinguish most of our L3
leaves. Bass technique, Rhodes vs FM, nylon vs steel and 808 vs analog are all masked
unknown. So this tests the *L2/L3 leaves with real-world names*, not the hardest
distinctions. Those still need the golden set and IDMT (bass technique, clean vs
distorted).

**Takeaways:**
1. The from-scratch model's tie with MERT holds on independent real music.
2. Real coarse co-training is not a free lunch. Drop "all OpenMIC" as a direction. If L1
   v2 is pursued, judge it on MoisesDB, not OpenMIC.
3. Source diversity (v4) points the right way on real data too, but needs more test clips
   to confirm. More MoisesDB windows per song (w60, w100) is the cheap next step.

## Real bass playing technique: IDMT-SMT-Bass (2026-10-10)

- **Data:** 2,654 isolated real electric-bass notes (fingered / picked / slap) from 4
  basses, plus a fretless subset. Test-only (NC-ND).
- **Caveat:** only 4 instruments, so an artist/instrument bootstrap is meaningless. Read
  these as point estimates. Leaves we never train (slap, fretless; no source provides
  them) are listed only to show their chance level.

| leaf (AP, chance) | CLAP | MERT | scratch v1 | scratch v4 | co-trained all |
|---|---|---|---|---|---|
| fingered (0.25) | 0.42 | 0.30 | **0.61** | **0.61** | 0.56 |
| picked (0.25) | 0.30 | 0.27 | 0.51 | **0.53** | 0.49 |
| slap (0.50, untrained) | 0.53 | 0.70 | 0.50 | 0.50 | 0.44 |
| fretless (0.12, untrained) | 0.11 | 0.18 | 0.18 | 0.16 | 0.18 |

- **Fingered vs picked transfers to real basses** for the from-scratch model (about 2× chance).
  That's better than LSO suggested (unseen *synthetic* bass 0.16–0.23). Isolated real
  notes are easier than full mixes, so this is a ceiling, not the in-mix number.
- **MERT probes are near chance on fingered/picked**, the reverse of LSO (where MERT led on
  bass technique). With 4 basses, don't read either direction as settled.
- **MERT clearly separates slap (0.70) without any slap label.** Pretrained features encode
  slap's percussive attack; a slap leaf would likely be cheap to add for MERT-style
  features.
- IDMT bass single-track (17 real bass lines, 1 group): too small to read. MERT 0.92 vs
  scratch 0.37 is anecdotal only.

## Real clean vs distorted: IDMT-SMT-Audio-Effects (2026-10-10)

- **Data:** 7,308 isolated real guitar notes/chords: NoFX, Distortion, Overdrive.
  The bass subset has no guitar leaf, so it's unused here. Test-only (NC-ND).
- **Metric:** AUC of the `guitar.electric.distorted` score, each effect vs NoFX.
  Positives are 86% of the set, so AUC is more readable than AP.

| model | mono: Distortion | mono: Overdrive | poly: Distortion | poly: Overdrive |
|---|---|---|---|---|
| CLAP probe | 0.74 | 0.70 | **0.96** | **0.88** |
| MERT probe | 0.51 | 0.48 | 0.45 | 0.42 |
| scratch v1 | 0.75 | **0.25** | 0.77 | **0.25** |
| scratch v4 | 0.73 | **0.13** | 0.81 | **0.18** |
| scratch co-trained all | 0.79 | 0.41 | 0.79 | 0.36 |

1. **The from-scratch models detect heavy distortion (AUC ~0.75–0.81), but rank
   overdrive *below* clean** (AUC 0.13–0.25 means systematically inverted). The
   synthetic "distorted" class is made of high-gain sources, so "distorted" was learned as
   *high gain*. Light drive falls on the clean side. v4 (more sources) made this
   *worse*. A leaf-definition gap (drive amount is a continuum), not a capacity one.
   **Fix:** render a range of drive amounts (pedalboard Distortion at a random gain,
   low→high) over the *clean* guitar sources, labelled distorted above a threshold.
   This is licence-clean and cheap.
2. **CLAP is best here, especially on chords (0.96 / 0.88).** Its contrastive text-audio
   pretraining evidently encodes "distorted" as a concept. That's the first task where CLAP
   beats everything else.
3. **MERT is at chance on isolated notes**, yet scored 0.68 AP on distorted guitar in real
   MoisesDB mixes. So **MERT's in-mix distorted-guitar score is likely carried by context**
   (rock arrangement / genre), not the guitar's timbre. That's a shortcut the isolated-note
   test exposes. Scratch models pass both tests (0.71–0.78 in mixes, 0.75+ on isolated heavy
   distortion), so their in-mix score is at least partly real timbre.

## L2b. Drive continuum (v6) + data-seed control (2026-10-10)

**What changed (`--fx-profile drive`):**
- Half of electric-guitar parts are rendered from a *clean* source at a random input level
  (−24…−12 dBFS RMS), through a random drive (0–40 dB).
- They're labelled by the **measured** nonlinearity (residual after the best linear fit,
  ≈ THD): ≤ 3% → clean, ≥ 10% → distorted, in between → `guitar.electric` with
  clean/distorted masked.
- Thresholds were fixed a priori from sine THD, not tuned on IDMT. Labelling by
  measurement matters because pedalboard's drive is level-dependent: the same knob gives
  2% or 11% THD depending on input level.
- **Outcome:** in practice 88% of drive-path stems measured distorted, 3% clean and 9%
  ambiguous.

**A second noise source, measured.** v4 re-rendered with `--seed 1`: same recipe and
holdouts, a different random draw of windows, sources and fx. That gives *data-sampling*
variance, on top of the training-seed variance from R-f.

| run | LSO† | LSO clean gtr | IDMT fingered | IDMT picked | overdrive mono‡ | overdrive poly‡ | dist poly‡ | MoisesDB-8 |
|---|---|---|---|---|---|---|---|---|
| v4, train seed 0 | 0.589 | 0.79 | 0.61 | 0.53 | 0.13 | 0.18 | 0.81 | 0.431 |
| v4, train seed 1 | 0.577 | 0.77 | 0.57 | 0.54 | 0.15 | 0.15 | 0.74 | 0.417 |
| v4, train seed 2 | 0.583 | 0.81 | 0.60 | 0.53 | 0.34 | 0.30 | 0.83 | 0.414 |
| v4, **data seed 1** | 0.571 | 0.77 | **0.43** | **0.46** | 0.14 | 0.27 | 0.81 | 0.402 |
| **v6 drive** | 0.580 | **0.70** | 0.45 | 0.44 | 0.31 | **0.59** | 0.83 | 0.432 |

† Mean AP over all scored synthetic leaves, computed identically for every row (not the
harness map_leaf, so the absolute values differ from R-a).
‡ IDMT-SMT-Audio-Effects AUC vs NoFX.

**Readings:**
- **Real bass technique is fragile under data resampling** (fingered 0.43–0.61 across
  v4 variants). v6's bass drop matches the data-seed control, so it is **noise, not a drive
  effect**. Any single-render IDMT bass number is unreliable. Bass technique is the
  most data-sensitive leaf pair; it needs more distinct basses (L3) more than anything.
- **Overdrive on chords: a real gain** (0.59, above every v4 variant's 0.15–0.30), though
  only to about chance. **Overdrive on single notes: no evidence** (0.31, inside v4's
  0.13–0.34).
- **Clean guitar: a real cost** (LSO 0.70, below every v4 variant's 0.77–0.81). The drive
  path converted half the clean parts, nearly all into distorted, halving clean coverage.
- MoisesDB and LSO overall: within noise.
- **Decision:** v6 is not adopted. `drive2` drives only *distorted* parts (clean coverage
  intact) and is under test as v6b.
- **Overfitting guard:** this is the second iteration judged on IDMT overdrive. If drive
  is iterated further, hold out half of IDMT's guitars as the selection set and report on
  the other half.

## L2c. `drive2` (v6b): drive continuum on distorted parts only (2026-10-10)

Same table as L2b, adding v6b:

| run | LSO† | LSO clean | LSO dist | IDMT fing | IDMT pick | overdrive mono | overdrive poly | dist mono | dist poly |
|---|---|---|---|---|---|---|---|---|---|
| v4 (4 variants) | 0.571–0.589 | 0.77–0.81 | 0.95–0.97 | 0.43–0.61 | 0.46–0.54 | 0.13–0.34 | 0.15–0.30 | 0.66–0.78 | 0.74–0.83 |
| v6 drive | 0.580 | 0.70 | 0.92 | 0.45 | 0.44 | 0.31 | 0.59 | 0.73 | 0.83 |

- **Overdrive is no longer inverted on single notes or on chords.** Heavy-distortion
  detection also improves; all four IDMT numbers are above the v4 range.
- **The LSO clean drop is one instrument.** The only held-out clean source is Shinyguitar.
  v6b gives it a distorted score of 0.42 (v4: 0.19). It *doesn't* show up on real music
  (pooled MoisesDB below: v6b clean 0.33 vs v4 0.32–0.39).
- IDMT bass is within the data-resampling range (L2b).
- **Decision:** `drive2` is the recommended fx profile for future renders. It gains on
  IDMT with no measured real-music cost. It's still opt-in until the golden set confirms.
- **Selection caveat:** v6 → v6b was the third look at IDMT overdrive. The v6b change
  was motivated by clean coverage (LSO), not by IDMT. Still, treat the IDMT overdrive
  numbers as mildly optimistic.

## L3c. More distinct instruments: NSynth (hand-labelled) + Iowa (v7, 2026-10-11)

**Why:** LSO (R-a) showed that leaves with 1–2 distinct instruments collapse on unseen
instruments, and licence-clean, finely labelled sources are scarce.

**What was added:**
- **NSynth** (CC BY 4.0, ~1,000 instruments, family labels only). Bradley labelled 133
  instruments by ear from 3.5 s phrases: 112 at leaf level, 20 unsure (kept coarse,
  subtree masked), 1 skip.
- **Cross-check:** his clean/distorted labels agree with NSynth's own `distortion` quality
  on 17/20 electric guitars. The 3 disagreements were masked to `guitar.electric`.
- **Bass technique** (fingered/picked) has no independent check.
- **Iowa MIS** (any use) adds 5 exact-labelled instruments. Every note was pYIN
  pitch-checked; failures were dropped (e.g. 27/104 double-bass files).
- **Engine and rendering:** a per-note `notes` engine (nearest recorded pitch, ≤±3
  semitones of resampling), and `--bandlimit-p 0.3` (7–8 kHz lowpass on a share of
  full-band sources) so NSynth's 16 kHz bandwidth isn't a label giveaway.
- **v7 render** = the v6b recipe (drive2, v4 holdouts, seed 0, 10k clips) plus these
  sources. 29% of stems come from the new sources (137 distinct instruments).

**Results** (same analysis as L2b/L2c; † and ‡ as defined there):

| run | LSO† | LSO clean | IDMT fing | IDMT pick | overdrive mono | overdrive poly | dist mono | dist poly | MoisesDB pooled-8 |
|---|---|---|---|---|---|---|---|---|---|
| v4 (4 variants) | 0.571–0.589 | 0.77–0.81 | 0.43–0.61 | 0.46–0.54 | 0.13–0.34 | 0.15–0.30 | 0.66–0.78 | 0.74–0.83 | 0.395–0.417 |
| v6b drive2 | 0.586 | 0.72 | 0.46 | 0.38 | 0.50 | 0.61 | 0.82 | 0.88 | 0.408 |
| **v7 NSynth+Iowa** | **0.603** | 0.65 | 0.45 | 0.38 | 0.39 | 0.52 | 0.86 | 0.83 | 0.412 |

LSO per leaf (unseen instruments; v4 range across 4 variants → v6b → v7):

| leaf | v4 range | v6b | v7 |
|---|---|---|---|
| nylon | 0.29–0.30 | 0.31 | **0.57** |
| steel | 0.46–0.56 | 0.45 | **0.73** |
| upright bass | 0.38–0.54 | 0.55 | **0.62** |
| fingered / picked bass | 0.21–0.25 / 0.14–0.16 | 0.22 / 0.17 | 0.25 / 0.18 |
| FM e-piano | 0.43–0.51 | 0.46 | **0.33 ↓** |
| Rhodes | 0.56–0.64 | 0.59 | 0.55 |
| clean electric | 0.77–0.81 | 0.72 | **0.65 ↓** |

**Readings:**
- **The M4 thesis, confirmed on the leaves that got instruments.** Nylon and steel
  generalization to unseen instruments nearly doubled (0.31 → 0.57, 0.45 → 0.73), far
  outside every variant's range. Upright bass improved too. This is the cleanest evidence
  yet that distinct instruments per leaf, not volume, drive fine-grained generalization.
- **Bass technique didn't move**, on synthetic LSO or real IDMT. 14 fingered + 7 picked
  NSynth basses, labelled from short phrases, add no measurable technique signal. Either
  the labels are noisy, or 3.5 s phrases don't carry technique.
- **FM became a catch-all.** 13 of 25 NSynth electronic keyboards were labelled FM. In v7
  the FM score rises on *non*-FM clips (mean 0.26 → 0.34), so precision drops. The
  ablation v7b (those 13 coarsened to `keys.electric_piano`) is running.
- **The clean-guitar drop is a new confusion.** The held-out clean electric source
  (Shinyguitar) is now mistaken for steel acoustic (score lift +0.17), not for distorted.
  Better acoustic coverage pulled a bright clean electric toward "steel".
- **Real music:** pooled MoisesDB v7 − v6b +0.004 [−0.021, +0.031], v7 − v4 −0.005
  [−0.041, +0.025], v7 − MERT −0.013 [−0.060, +0.030] (ties); v7 − CLAP +0.109 [+0.073,
  +0.165]. MoisesDB masks nylon/steel, so it can't see the main gain. That's the golden
  set's job.
- **IDMT overdrive** is slightly below v6b but still above v4 on chords. With one run each
  and the v4 spread, this isn't separable from noise.
- **Selection caveat:** this was the first look at v7 on every test, and nothing was tuned
  on these numbers. v7b is motivated by the FM diagnosis (LSO), so its LSO FM number is
  the one to discount.

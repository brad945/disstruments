# Builder's Debrief — M4: Closing the Synthetic→Real Gap (in progress)

> Plan: `docs/M4_PLAN.md`. Baseline = M3 from-scratch CNN (1.22M params, synthetic v1,
> 8k clips): OpenMIC trained-9 AP 0.785, synthetic test map_leaf 0.923. Δs are paired
> artist bootstraps (400 resamples) on OpenMIC test trained-9 mean AP.

## Results (2026-10-09)

| lever | OpenMIC trained-9 | Δ vs baseline [95% CI] | OpenMIC untrained-11 | synthetic map_leaf |
|---|---|---|---|---|
| baseline | 0.785 | – | 0.326 | 0.923 |
| **L1 co-train, all OpenMIC train (14,915 real clips)** | **0.870** | **+0.085 [+0.070, +0.099]** | 0.725 | **0.876 ↓** |
| L1 co-train, commercial-licence clips only (≈1.3k) | 0.804 | +0.019 [+0.007, +0.032] | 0.583 | 0.856 ↓ |
| L2 production randomization v2 (re-rendered 10k) | 0.783 | −0.002 [−0.012, +0.010] | 0.331 | – |

**1. Real co-training buys coarse real-world accuracy and costs fine-grained accuracy.**
- **Gains:** organ +0.13, synth +0.17, trumpet +0.15, bass +0.09. The model now clearly
  beats MERT-MLP on real music (+0.083, CI [+0.064, +0.100]).
- **Costs:** on synthetic test, the *fine* distinctions regress. Rhodes 0.77→0.61, FM
  0.84→0.70, nylon 0.89→0.80, synth lead/pluck ~−0.08 each; map_leaf 0.923→0.876.
- **Cause:** 15k coarse real clips outweigh 8k fine synthetic ones, so the shared features
  tilt toward coarse family identity.
- **Untrained classes jumped** (0.33→0.73), which is the honest tell that part of the gain
  is *learning OpenMIC itself*. Train and test come from the same source and the same
  crowd-labelling, so OpenMIC test is no longer an independent judge for L1 models.
  **An independent real test (golden set / MoisesDB) is required before claiming L1 helps
  real-world recognition in general.**

**2. The licence cost, measured.** Restricting real co-training to commercially usable
clips (~9% of OpenMIC) keeps only a quarter of the coarse gain (+0.019 vs +0.085).

**3. Production randomization (L2) did nothing measurable.** It added convolution rooms,
amp/cab EQ, saturation, MP3 round trips and noise. So the real-music gap isn't explained
by these production differences; more likely by **source timbre diversity** (L3, now
rendered) and **musical context** (Lakh MIDI arrangements vs real playing). A plausible
negative result, recorded as such.
